# TopZak — исправленная адаптивная версия

## Что изменено

- Удалены пустые демонстрационные карточки «Наши проекты», включая связанные ссылки.
- Удалены цены из конструктора и из отдельных услуг. Вместо цены — индивидуальное обсуждение проекта.
- Выбранные услуги передаются в форму заявки при нажатии «Обсудить проект».
- Русская, армянская и английская версии доступны с компьютера и телефона; переведены карточки команды и подписи контактной формы.
- Исправлена мобильная композиция первого экрана: робот находится внутри главного экрана, не растягивает страницу по горизонтали и не закрывает основной текст.
- Исправлено центрирование контейнеров и перенос длинных слов, в том числе в армянской версии.
- Основные блоки рассчитаны на изменения текстов и числа карточек без ручного подбора ширины.

## Как изменить услуги

Все шесть карточек направлений TopZak находятся в `index.html` внутри блока `<div class="standalone-grid">`. Там редактируется русский текст, который виден до переключения языка. Переводы карточек — в `js/main.js` в словарях `ru`, `en`, `am` по ключам `stand.*`.

Карточки имеют гибкую CSS-сетку: 3 в ряд на больших экранах, 2 на планшетах и 1 на телефонах. Для изменения дизайна см. конец `main.css` — раздел `TOPZAK SERVICES`.

## Как редактировать тексты

В `js/main.js` найдите `const translations = { ... }`. Там находятся словари `ru`, `en` и `am`. Меняйте тексты сразу для всех трёх языков. Можно менять длину текста: блоки используют гибкие размеры и переносы.

Тексты футера находятся в `index.html` в атрибутах `data-footer-ru`, `data-footer-am`, `data-footer-en`.

При изменении HTML убедитесь, что атрибуты `data-i18n`, `data-i18n-html` и `data-i18n-placeholder` ссылаются на существующие ключи в трёх словарях.

## Перед публикацией на GitHub Pages

1. Сделайте резервную копию действующего сайта.
2. Загрузите файлы **из папки `TopZak/`** в корень сайта в репозитории (не вложенную папку `TopZak/TopZak`).
3. Проверьте первый экран и все языки на собственном телефоне и компьютере; при необходимости обновите кэш браузера.
4. **Реально отправьте тестовую заявку.** Теперь форма использует `https://formsubmit.co/ajax/topzak.agency@gmail.com`. **ВАЖНО: новый адрес требуется подтвердить через письмо от FormSubmit** (первая тестовая заявка вызывает письмо активации). Реальную доставку нельзя считать проверенной, пока вы не активировали адрес и не получили письмо с тестовой заявкой. Не тестируйте отправку из `file://`; опубликуйте страницу на GitHub Pages или запустите локальный сервер.
5. Ссылки Instagram, Telegram для сообщений, Telegram-канала и WhatsApp уже добавлены. Неизвестная ссылка TikTok удалена, чтобы не было нерабочей кнопки.
6. Отдельный блок портфолио пока удалён; реальные кейсы можно добавить позже, когда появятся готовые работы.

Подробнее о выполненных проверках — в `QA-REPORT.md`.

## Мобильная шапка и первый экран (референс Figma)

На мобильных экранах отображается **одна кнопка текущего языка**, по нажатию раскрывается список остальных языков. Значок телефона в шапке набирает `+37498031385`.

Позиция робота и отступы главного экрана задаются в **самом конце `main.css`**, в разделе `Figma-inspired MOBILE FIRST SCREEN`. CSS-переменные `--hero-top` и `--hero-bottom` контролируют расстояние над и под заголовком и кнопками. Размер блока меняется вместе с длиной текста; у картинки робота абсолютное позиционирование внутри первого экрана.

На телефонах вступительный абзац первого экрана скрыт по аналогии с указанным макетом Figma; на компьютере он остаётся видимым.
